# معماری کشف خودکار ساختار و ورود معنایی داده‌ها

## هدف

ورود منبع جدید نباید مستلزم نوشتن Adapter یا قواعد تبدیل اختصاصی برای همان منبع باشد. منطق پردازش باید در موتور عمومی NexusOps قرار گیرد. Dataset Registry قرارداد canonical مقصد را تعریف می‌کند؛ اما ساختار منبع، نوع مقادیر، فیلدهای تو‌در‌تو و نامزدهای معنایی باید در زمان اجرا کشف شوند.

## اصل تفکیک

- **قواعد عمومی موتور:** خواندن جریانی، تشخیص ساختار، پروفایل آماری، تشخیص نوع فیزیکی، استخراج ساختار JSON، پیشنهاد نگاشت معنایی، امتیاز اطمینان، نرمال‌سازی، اعتبارسنجی و انتشار اتمیک.
- **قرارداد canonical:** معنای فیلدهای مقصد و نقش تحلیلی آن‌ها؛ مستقل از نام ستون‌های هر منبع.
- **اطلاعات مختص منبع:** فقط metadata و گزارش کشف‌شده؛ نباید به کد اجرایی اختصاصی منبع تبدیل شود.

## جریان هدف


## قواعد ایمنی و صحت

1. پروفایل‌گیری باید جریانی و دارای حافظه محدود باشد؛ فایل کامل در RAM بارگذاری نمی‌شود.
2. تشخیص نوع فیزیکی از داده مشاهده‌شده انجام می‌شود؛ نوع فیزیکی به‌تنهایی اثبات معنای فیلد نیست.
3. نگاشت معنایی باید با نام فیلد، نمونه مقادیر، ساختار تو‌در‌تو، توزیع داده و تعریف فیلدهای Registry ارزیابی شود.
4. نگاشت با اطمینان پایین یا چند تفسیر معتبر، نباید خودکار منتشر شود؛ سیستم باید گزارش ابهام تولید کند.
5. فیلدهای فاقد معادل canonical حذف می‌شوند؛ Schema مقصد به خاطر هر منبع گسترش پیدا نمی‌کند.
6. هیچ مقدار مشتق‌شده‌ای مانند demand_score بدون تعریف و اعتبارسنجی روش محاسبه تولید نمی‌شود.
7. نرمال‌سازی رکوردی و کنترل کیفیت مجموعه‌ای دو مرحله مستقل‌اند؛ موفقیت نوع داده به معنی معتبر بودن کل Dataset نیست.
8. هیچ داده‌ای پیش از عبور از همه gateها در Alias اصلی قابل مشاهده نمی‌شود.

## وضعیت پیاده‌سازی این تغییر

ماژول `tools/source_discovery.py` و CLI `scripts/profile_source_dataset.py` مرحله اول موتور عمومی را پیاده می‌کنند: پروفایل‌گیری جریانی CSV، تشخیص نوع‌های متداول، شمارش nullها، نمونه و مقادیر پرتکرار با سقف حافظه، و استخراج کلیدهای JSON تو‌در‌تو. این مرحله read-only است و هیچ داده‌ای به Elasticsearch نمی‌نویسد.

این تغییر هنوز semantic mapper، تبدیل خودکار به canonical، quality gates مجموعه‌ای یا انتشار خودکار را پیاده‌سازی نمی‌کند. این‌ها مراحل بعدی هستند و نباید با یک نگاشت حدسی جایگزین شوند.
